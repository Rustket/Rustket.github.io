Three ways to get started

Choose your path
to Rustket.

Use the verified release installer, install through Homebrew, or build from source with Cargo. All methods work on supported macOS and Linux systems.

Release installer ↓ Homebrew ↓ Cargo ↓

Before you begin

Supported platforms

  • macOSARM64 · x86_64
  • LinuxARM64 · x86_64

The release installer also requires curl, tar, awk, git, and either shasum or sha256sum.

01

Recommended

Install a prebuilt release

The script detects your operating system and CPU architecture, downloads the matching Rustket 0.1.0 archive and its checksum list, and verifies the archive before installation. It installs the CLI to ~/.rustket/bin, clones the official Rustket/rustket-bits tap if it is not already present, and adds the bin directory to Bash, Zsh, or Fish configuration when recognized.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Rustket/rustket/main/install.sh)" && export PATH="$HOME/.rustket/bin:$PATH"

  1. 1
    Paste the command into Bash or Zsh.

    The trailing export makes Rustket available in the current shell too.

  2. 2
    Open a new Fish shell.

    The installer adds the Fish path setting; start a new shell to load it.

  3. 3
    Install a package.

    The official tap is preconfigured, so you can run rustket install ripgrep.

macOS note for version 0.1.0

The prebuilt macOS binaries are not code-signed or notarized. If Gatekeeper reports that Rustket could not be verified, use the Cargo source installation below rather than bypassing the warning. SHA-256 checks integrity but does not replace Apple's signing and notarization.

02

Homebrew

Install with brew

Install the Rustket CLI from its Homebrew tap, then add the official package bits tap so Rustket can find packages such as ripgrep.

brew install Rustket/rustket/rustket
rustket tap add Rustket/rustket-bits

03

Build locally

Install from source

If you already have Rust and Cargo installed, Cargo can build Rustket directly from the GitHub repository. Then add the official bits tap.

cargo install --git https://github.com/Rustket/rustket.git
rustket tap add Rustket/rustket-bits

Cargo installs the Rustket CLI in ~/.cargo/bin. Rustket-managed application commands go in ~/.rustket/bin; add that directory to your PATH if it is not already there:

export PATH="$HOME/.rustket/bin:$PATH"

Next up

Install your first bit

Rustket installs command-line executables, not macOS .app bundles. The official tap is preconfigured with the release installer; add it manually if you used another install method.

rustket install ripgrep rustket list rustket doctor
