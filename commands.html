Command reference

Package commands

Use a bit's name as it appears in the tap definition.

rustket install <bit>Install a package

Downloads the current platform's archive, verifies its SHA-256 digest, unpacks it into the cellar, and links its executable into ~/.rustket/bin.

rustket install ripgrepInstalls the ripgrep bit.
rustket install <bit> --skip-verifySkip checksum verification

Skips the SHA-256 check. This option is intended for development only; normal installs verify by default.

rustket uninstall <bit>Remove a package

Removes the package's command link and its stored files under ~/.rustket/cellar.

rustket listList installed commands

Prints the names currently present in Rustket's ~/.rustket/bin directory.

rustket search <query>Search available bits

Matches the query, without case sensitivity, against bit names found in configured taps.

rustket info <bit>Inspect a bit

Displays the bit's name, version, and platform keys defined in its TOML manifest.

Package sources

Tap commands

Taps are GitHub repositories with package definitions in a bits/ directory.

rustket tap add <owner/repo>

Clone a GitHub tap. You can also pass its GitHub HTTPS URL.

rustket tap add Rustket/rustket-bits
rustket tap list

Show the configured taps by owner and repository.

rustket tap remove <owner/repo>

Remove the selected tap from the local taps directory.

rustket tap update

Pull fast-forward updates for each configured tap.

Upkeep

Maintenance
commands

Check your setup or refresh Rustket and the packages it manages.

rustket doctor
Check your setup

Reports platform, Rustket directories, PATH, Git, and broken command links. Returns an error if checks fail.

rustket update
Update Rustket

Refreshes configured taps, then reinstalls the rustket bit itself.

rustket upgrade
Upgrade installed bits

Refreshes taps, then reinstalls each listed bit. It attempts remaining upgrades after a failure and reports an error if any failed.
